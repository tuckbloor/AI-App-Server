AI APP SERVER v0.8.0 - MODULAR AI SERVER

LOCAL WINDOWS (NO SSL):
  1. Extract ZIP to E:\ (E:\ai-app-server).
  2. Double-click START HERE.bat.
  3. Your working app opens in the browser. Admin is at /admin.

PRODUCTION:
  See production/README.md for the HTTPS deployment candidate.
  Production is not the local one-click mode and requires a real domain and TLS reverse proxy.
  Before enabling production, Security > Production readiness shows missing checks.

UPDATES:
  Use UPDATE ENGINE.bat. It backs up the previous engine and SQLite database.
  Your app, database and port settings are kept outside engine/.
